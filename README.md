# Panda Welcome Back

Upload the EXTRACTED contents of this ZIP into the root of a GitHub repository. GitHub does not unpack an uploaded ZIP for you.

Files:
- index.html: website page
- styles.css: responsive layout and transitions
- script.js: Continue, Back, dots, keyboard arrows, and swipe navigation
- assets/1.png through assets/5.png: exact, unmodified pictures from the uploaded ZIP

No backend is needed. This is a static site. To publish with GitHub Pages, open the repository Settings > Pages and choose Deploy from a branch, main, /(root).

Keep the repository private if you do not want the personal photographs in a public repository.
